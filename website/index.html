AI OPERATIONS CENTRE + OPS MIND

AI that works with your operational guardrails.

Get help investigating infrastructure issues while keeping review and control in the operator's hands.

Live investigations can collect bounded Kubernetes status, events, logs and metrics. Cross-system investigations may also collect a minimal host summary and Docker container inventory. The collector does not query Kubernetes Secret values, ConfigMap values, container environment variables or Docker logs.

GOOD TO KNOW

Questions, answered.

Start here for the essentials, then head to the repository for the full technical detail.

Which operating systems have prebuilt bundles?

The current Fast Installer release provides bundles for Linux x86-64, macOS Apple Silicon and Intel, and Windows x86-64. Check the release page for the latest available assets.

Does KubeDock replace kubectl or my cloud CLI?

No. KubeDock is a desktop workspace that works with your configured tooling, identities and permissions. It does not grant access you do not already have.

Does AI automatically change my infrastructure?

AI investigations and right-sizing recommendations are advisory. Remediation proposals require review, and the planner does not submit or execute the operation itself.

How does the lightweight installer differ?

The Fast Installer bundles omit optional Qwen3-TTS/PyTorch and Qt WebEngine/Chromium components to reduce installation size. Some optional capabilities may therefore be unavailable in those bundles.

Where can I find all versions?

Visit the Downloads page to load public GitHub Releases, inspect available assets and open the original release notes.

How do I report a security vulnerability?

Please report suspected vulnerabilities privately through the GitHub security advisory form, not through public issues.

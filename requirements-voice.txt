# Optional voice features for Ops Mind: microphone input and offline narration.
#
# PyAudio needs the native PortAudio library:
#   macOS:          brew install portaudio
#   Debian/Ubuntu:  sudo apt install portaudio19-dev
#   Fedora/RHEL:    sudo dnf install portaudio-devel
#   Windows:        pip install --only-binary=:all: PyAudio
#
# Install on top of the core requirements:
#   pip install -r requirements.txt -r requirements-voice.txt
#
# Without these packages typed Ops Mind requests still work. Microphone input
# and offline narration report when their optional runtime is missing.
